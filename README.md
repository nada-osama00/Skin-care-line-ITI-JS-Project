# Skin Care Line 🌿

A responsive, luxury-skincare storefront built with **vanilla JavaScript, HTML, and CSS** — no frameworks. Products are rendered dynamically from a JSON catalog, with a full shopping flow: browse → filter → quick view → cart → checkout.

> 🎓 Built as a team project during the **ITI (Information Technology Institute)** JavaScript course.

## ✨ Features

- **Home page** — hero slider, trending-now section, product filtering, quick-view modal, scroll animations
- **Shop** — sidebar filters, toolbar sorting, pagination, breadcrumb navigation
- **Product details** — per-product page driven by `data/products.json`
- **Cart & Checkout** — add/remove items, order summary, checkout form
- **Wishlist** — save products for later
- **User profile** — login / register flow with profile page
- **Search** — site-wide product search
- **Premium UI** — custom typography (GT Standard, Satoshi, Urbanist) and a polished, consistent design system

## 🗂️ Project Structure

```
├── index.html            # Home page
├── pages/                # shop, details, cart, checkout, wishlist, profile
├── js/                   # feature scripts (home/, shop, cart, checkout, ...)
├── css/                  # per-page styles + shared root styles & fonts
├── data/products.json    # product catalog driving the UI
└── media/                # images & banners
```

## 🚀 Run It

No build step needed — it's pure HTML/CSS/JS:

1. Clone the repo
2. Open `index.html` in your browser (or use VS Code's **Live Server** for best results)

## 🛠️ Tech
